# Hi 👋 My name is tonton

## Kernel Developer | Just a dev who loves Linux

I am a Kernel Developer driven by a deep fascination with the Linux operating system and low-level mechanics. I enjoy diving into the core layers of the OS, exploring kernel architectures, tracing system calls, and understanding how hardware interacts directly with software. For me, working with Linux isn't just a job or a technical domain—it's a genuine passion and a continuous learning journey.

To streamline my development process, I actively integrate AI tools into my daily workflow. I leverage AI to accelerate code generation, automate tedious boilerplate, assist in debugging complex kernel logic, and refactor code efficiently. Combining deep-level systems engineering with modern AI-assisted tools allows me to focus on high-level system design, memory optimization, and performance while keeping the core codebase clean, maintainable, and effective.
